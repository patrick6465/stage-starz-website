STAGE STARZ COMPLETE WEBSITE + STORE ADMIN

This package combines the complete website ZIP you uploaded with the database-backed Stardust Ship-it-Shop and private admin dashboard.

Included:
- All existing Stage Starz pages and assets
- Store at /store
- Admin dashboard at /admin
- Add, edit, hide, and delete products
- Prices and sale prices
- Inventory, sizes, colors, categories, and image URLs
- Product-specific fulfillment fees
- Add-a-Name option by product
- Global name charge set to $10.00
- Store email, Venmo, sales tax, and shipping settings

RUN ON WINDOWS
1. Install Python 3.
2. Extract this ZIP.
3. Double-click start-store.bat, or run:
   py -m pip install -r requirements.txt
   py app.py

Main website: http://127.0.0.1:5000/
Store: http://127.0.0.1:5000/store
Admin: http://127.0.0.1:5000/admin
